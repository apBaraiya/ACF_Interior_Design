# Artima Architecture

Artima Architecture is a custom-built, responsive architecture and interior design website developed using WordPress, PHP, HTML, CSS, JavaScript, and Advanced Custom Fields (ACF).

The website was developed with a focus on creating a fully customizable, page-specific content management system while maintaining a clean and structured frontend architecture.

# Project Overview

The website showcases architectural and interior design services, projects, company information, and other business content through a modern and responsive interface.

Instead of relying on a generic page builder or a single repeater-based content structure, the website uses page-wise ACF Field Groups to provide dedicated content management for each individual page.

Each page has its own set of custom fields based on the content and layout requirements of that page.
